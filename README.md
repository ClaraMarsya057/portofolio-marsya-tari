# **Portfolio Website - Marsya & Tantari**  

**Repository Name:** `portofolio-marsya-tari`  

## **Project Description**  
A **personal portfolio website** built with **HTML, CSS, and JavaScript**, showcasing the skills and projects of Marsya & Tantari, students from **SMK TI Bali Global Jimbaran (PPLG Major)**.  

### **Key Features**  
✅ **Responsive Design** – Works on mobile & desktop  
✅ **Modern UI** – Clean layout with Bootstrap 5  
✅ **Interactive Sections** – Skills progress bars, portfolio gallery  
✅ **Social Media Links** – Easy contact options  

### **Technologies Used**  
- **HTML5** (Structure)  
- **CSS3** (Styling)  
- **Bootstrap 5** (Responsive Grid & Components)  
- **Font Awesome** (Icons) 

### **Setup**  
1. Clone the repository  
2. Open `index.html` in any browser
